
# Changelog

All notable changes to Alpenglow Workspace are documented here.

## [1.1.0]

- Added the **Alpenglow Workspace Dimmer** theme, a darker variant with a `#292728` background.
- Focused inputs and form fields now use the orange accent `#DA6C4B` instead of the default blue.

## [1.0.0] - Initial Release

- Initial release of Alpenglow Workspace.
- Warm charcoal workspace palette.
- Consistent styling across VS Code workbench surfaces.
- Custom syntax highlighting.
- Integrated terminal color palette.
